# Política de privacidad — Rclone personal

Actualizada el 20 de octubre de 2026.

## Para qué se utiliza

Esta conexión permite acceder a Google Drive desde
un equipo personal con Fedora mediante Rclone.

## Qué datos utiliza

Con permiso del propietario, Rclone puede consultar
archivos y carpetas, descargar documentos, guardar
cambios, renombrar y eliminar elementos.

El acceso se utiliza para realizar las operaciones
que solicita el usuario.

## Dónde se guardan los datos

Los archivos permanecen en Google Drive.
El equipo puede guardar copias descargadas y
archivos temporales para abrirlos más rápidamente.

Las credenciales se guardan en la configuración
local de Rclone y deben mantenerse privadas.

## Privacidad

Esta conexión no vende datos ni los utiliza
para publicidad.

Los documentos y las credenciales no se publican
en esta página ni en GitHub.

## Cómo retirar el acceso

El propietario puede retirar el permiso desde
las conexiones de terceros de su cuenta de Google.

Esto no elimina las copias ya descargadas al equipo.
